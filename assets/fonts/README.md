# Bundled typography

The game uses Fraunces 9pt Soft Regular for word tiles and Fraunces 72pt Soft
Italic for the small signature. Both are unmodified static font files by
Phaedra Charles and Flavia Zimbardi, distributed under the SIL Open Font License
1.1; see [Fraunces-OFL.txt](Fraunces-OFL.txt).

Source: <https://github.com/undercasetype/Fraunces>

These are bundled assets, so running the game never downloads fonts.
